## 🚀 Featured Projects

### 🏦 [Desjardins — Claims Modeling & Pricing Pipeline](#) `Internship`
End-to-end pipeline ingesting agent claims data via API, transforming through Python/R, and serving an **XGBoost / Logit GLM** pricing model.
- Engineered **500+ candidate features** through EDA, domain-driven construction, and NLP on unstructured claims notes (EN/FR)
- Improved pricing accuracy by **~20%**, cut data discrepancies by **30%**, and accelerated reporting by **25%** via Power BI dashboards
- *Tech: Python, R, SQL, XGBoost, Pandas, NLP (TF-IDF), Power BI*

### 🕵️ [Scotia Bank AML Detection — IMI Big Data & AI Case Competition](#) `Top 15%`
Semi-supervised AML anomaly detection on **200K+ transactions** under a strict **2% FPR constraint** — because every false flag costs analyst hours.
- Stacked ensemble: **Denoising Autoencoder + Isolation Forest + Logit Regression**
- PCA-driven clustering across **7 customer segments** to make the model population-aware
- Achieved **AUC-ROC of 0.82** under the operational constraint
- *Tech: Python, scikit-learn, PyTorch, PCA, K-Means*

### 🔗 [Bitcoin Illicit Transaction Detection via GCN](#) `Team Lead`
Stacked **Graph Convolutional Network** in PyTorch Geometric on 200K Bitcoin transactions, modeling temporal decay of money-laundering patterns.
- Designed **Random / Chronological / Rolling-Window** splits to simulate realtime monitoring and prevent temporal leakage
- Mini-batch sampling + dropout regularization to handle extreme class imbalance
- *Tech: PyTorch Geometric, Python, NetworkX*

### 🎓 [UofT Student Retention Modeling](#) `VP-Provost Office`
Led a 3-member statistical consulting team to predict student churn across **100K+ LMS records**.
- Built SMOTE-balanced ML pipeline (Regression / Decision Trees / Random Forest / Cumulative Logit) with K-fold CV + hyperparameter tuning
- Reached **89% sensitivity** on at-risk identification
- Delivered **SHAP-based interpretability dashboards** so non-technical administrators could act on risk factors
- *Tech: Python, scikit-learn, SQL, SHAP, Power BI*

### 📈 [GF Securities — Portfolio Analytics Dashboards](#) `Financial Products`
Built Tableau interactive dashboards for portfolio managers monitoring **300+ IPO client** portfolios.
- Visualized portfolio composition, daily P&L trends, and **trading volume heatmaps per ticker**
- Automated **50K+ record matching** via Excel VBA and Pivot Tables — manual effort down ~60%
- *Tech: Tableau, SQL, Excel/VBA, Power Query*
